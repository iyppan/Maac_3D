# IYAL STUDIOS | 3D & Game Art Career Directory & Industry Matrix

A state-of-the-art, high-performance web application designed for students, 3D artists, game developers, animators, riggers, and recruiters — **fully redesigned and mobile-optimized for smartphones and tablets**, branded as **IYAL STUDIOS**.

This platform catalogs **44 specialized industry production roles** across **5 core software suites**, mapping out the entire career landscape for AAA Video Games, Feature Film VFX & OTT, Photorealistic Architectural Visualization, Digital Fashion, and Real-Time Virtual Production.

---

## 📱 Mobile-First Features

### 1. 📲 App-Like Fixed Bottom Navigation Bar
- Seamless one-thumb navigation bar fixed at the bottom on all mobile devices:
  - 🎴 **Roles**: Instant catalog card browser.
  - 📋 **Matrix**: Master spreadsheet table.
  - 📊 **Analytics**: Market share breakdown & production hub rankings.
  - 🧭 **Pipelines**: Studio production workflows.
  - 🔖 **Saved**: Instant access to your personal shortlist with live counter badge.
- Native safe-area-inset support for iPhone notch/home indicators and bezel-less Android displays.

### 2. 🗂️ Mobile Filter Bottom Sheet
- Clean mobile search toolbar featuring a dedicated **Filters** button with active filter counter indicator.
- Tapping it slides up a native iOS/Android style **Bottom Sheet Drawer** to filter by Software Suite, Industry, Production Hub, or Sort Order without pushing down your content.

### 3. 👆 Horizontal Swipeable Software Strip
- Touch-friendly, momentum-based swipeable software pills at the top (`All`, `UE5`, `Maya`, `3ds Max`, `Substance`, `Marvelous`) with active neon glows and live role counts.

### 4. 📄 Bottom Sheet Modals with Pull Handles
- Role blueprints, career matcher quiz, and shortlist drawers slide up smoothly from the bottom on mobile devices with visual grab handles and sticky action footers.

## 🚀 Full Platform Capabilities

### 1. 🎴 Dynamic Role Catalog (Grid Card View)
- 44 interactive cards with glowing software color branding:
  - **Autodesk 3ds Max** (Cyan `#06b6d4`)
  - **Autodesk Maya** (Emerald `#10b981`)
  - **Adobe Substance 3D Painter** (Amber `#f59e0b`)
  - **Marvelous Designer** (Hot Pink `#ec4899`)
  - **Unreal Engine 5** (Electric Indigo `#6366f1`)
- Software badges, Role IDs (`UE5-01`, `MAX-04`, `MAYA-02`, etc.), primary industry tags.
- Interactive companion software tags (tap to filter related roles).
- Top production hubs indicators (Bengaluru, Mumbai, Chennai, Hyderabad, Pune, Delhi NCR, Remote).
- Actions: **View Blueprint**, **Add to Compare (up to 3)**, **Bookmark to Shortlist**.

### 2. 📋 Master Spreadsheet Matrix (Table View)
- High-density, searchable, and sortable spreadsheet matrix for quick scanning.
- Displays Role ID, Software, Title, Industry, Core Responsibilities, Companion Tools, and Geographic Hubs.

### 3. 📊 Ecosystem Analytics & Hub Distribution
- **Market Share Visualizer**: Live percentage bars for all 5 software suites.
- **Top Production Hub Ranking**: Ranked list of leading production cities with active role counts.
- **Cross-Discipline Tool Synergy Cloud**: Frequency counter for companion tools like ZBrush, Python, Nuke, Houdini, and V-Ray.

### 4. 🧭 Production Pipeline Roadmaps
Visual step-by-step studio pipelines mapping which roles operate at each production phase:
1. **AAA & Indie Game Art Pipeline** (Concept -> Modeling -> Marvelous Cloth -> Substance Surfacing -> UE5 Level Assembly -> Niagara VFX -> C++ Gameplay)
2. **Feature Film & OTT VFX Pipeline** (Previs -> Maya Modeling -> Rigging TD -> CFX Simulation -> Keyframe Animation -> Arnold LookDev -> ICVFX Virtual Stages)
3. **ArchViz & Real-Time Digital Twin Pipeline** (CAD Blueprints -> 3ds Max Structures -> Soft Goods -> Corona Renders -> UE5 Pixel Streaming)
4. **Digital Fashion & Virtual Retail Pipeline** (2D Pattern Cuts -> Fabric Physics Simulation -> PBR Weave Textures -> Game Quad Retopology -> Metaverse Presentation)

### 5. ⚖️ Side-by-Side Role Comparison Matrix
- Compare up to 3 roles simultaneously.
- Direct side-by-side analysis of responsibilities, tool stacks, hubs, and demand ratings.

### 6. ⚡ Interactive Career Pathway Matcher (3-Step Quiz)
- Interactive wizard matching artistic vs. technical preferences and creative passion to the best-suited 3D career roles with instant recommendations.

### 7. 💾 Personal Shortlist & Export System
- Bookmark roles to browser `localStorage`.
- One-click export to **CSV** or **JSON**.
- Formatted **Print / PDF** specification sheet.
